## 📱 プロジェクト概要

### 『レシート即！メモ』とは
レシートをスマホで撮影するだけで「いつ・どこで・いくらで（値引きありか）」買ったかをカテゴリ単位で記録・一覧化できる、買い物サポートWebアプリです。

* **コンセプト**: 「家計簿をつける」から「次の買い物をスマートにする」へ。
* **狙い**: 既存の家計簿アプリのような「支出管理」ではなく、買い物の現場で「次にどこで買えば一番得か」を1秒で解決する生きた価格データベースを提供します。
* **ターゲット**: 20〜30代の自炊層（タイパ重視の生活者）

### 主な特長
1. **「カテゴリ束ね」による見やすさ**: 「牛乳」「卵」などのカテゴリ単位に自動分類し、店ごとの最新価格を一画面で比較。
2. **「値引きあり」の履歴可視化**: 定価と値引き品を明確に区別して記録し、リアルな店頭価格を把握。
3. **「片手操作」に特化したUI**: 買い物中に売り場でサッと確認できるスマホ最適化設計。
