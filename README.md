# レシート即！メモ

プロジェクトのリポジトリへようこそ！
チームメンバーの皆さん、開発お疲れ様です。本プロジェクトでは、レシート撮影から賢い買い物をサポートするWebアプリ『レシート即！メモ』の開発を進めていきます。ルールに沿ってスムーズな共有・開発を行いましょう！

---

## 📱 プロジェクト概要

### 『レシート即！メモ』とは
レシートをスマホで撮影するだけで「いつ・どこで・いくらで（値引きありか）」買ったかをカテゴリ単位で記録・一覧化できる、買い物サポートWebアプリです。

* **コンセプト**: 「家計簿をつける」から「次の買い物をスマートにする」へ。
* **狙い**: 既存の家計簿アプリのような「支出管理」ではなく、買い物の現場で「次にどこで買えば一番得か」を1秒で解決する生きた価格データベースを提供します。
* **ターゲット**: 20〜30代の自炊層（タイパ重視の生活者）

### 主な特長
1. **「カテゴリ束ね」による見やすさ**: 「牛乳」「卵」などのカテゴリ単位に自動分類し、店ごとの最新価格を一画面で比較。
2. **「値引きあり」の履歴可視化**: 定価と値引き品を明確に区別して記録し、リアルな店頭価格を把握。
3. **「片手操作」に特化したUI**: 買い物中に売り場でサッと確認できるスマホ最適化設計。

### チーム体制
* **信治**: リーダー / スケジュール管理 / フロントエンド
* **藤田**: バックエンド / フロントエンド
* **奥田**: 資料作成 / 情報収集 / データ入力
* **安武**: 資料作成 / 情報収集 / データ入力
* **山本**: 資料作成 / データ入力 / 発表準備

## 🛠️ GitHub運用ルール

### 共通ルール
* **日付形式**: `yy/MM/dd`（例: `26/11/07`）
* **変更内容（コミット・PRタイトル）**: 日付のあとに、日本語で短く記載（例: `26/11/07 購入日の表示を統一`）
* **説明文（コミット・PR本文）**: 日本語で簡素に変更内容を記載（箇条書きで1〜3行ほど）
* **ブランチ**: メンバーごとに自分のブランチ（名字のローマ字。例: `fujita`、`nobuji`）で作業し、`main` には直接コミットしない
* **`main` への反映**: 自分のブランチから `main` へ、GitHub上でプルリクエスト（PR）を作成してマージする

### 1. 開発作業の流れ（基本コマンド）

作業を始める前・作業中・完了時の基本コマンド手順です。
（Windowsの PowerShell で `npm` が動かないときは、`npm.cmd` と入力してください。）

#### ① 作業を始める前（自分のブランチに移動する）
```bash
# 自分のブランチに移動（例: fujita）
git checkout fujita

# リモート（GitHub）の最新コードを取得
git pull origin fujita
```

#### ② 作業中（アプリを動かして確認する）
```bash
# 初回だけ: 必要なパッケージをインストール
npm install

# 開発用サーバーを起動（表示されたURL、通常は http://localhost:5173 を開く）
npm run dev
```
* 初回だけ、プロジェクト直下に `.env` ファイルを作り、Supabase の接続情報（`VITE_SUPABASE_URL` と `VITE_SUPABASE_ANON_KEY`）を書きます。値はチームの担当者に確認してください。`.env` はGitに上げません。
* レシート解析（`supabase/functions/parse-receipt`）を変更したときは、`npm run deploy-functions` でデプロイします。pushやマージだけでは反映されません（先に `npx supabase login` が必要です）。

#### ③ コミットする（変更を記録する）
```bash
# 変更したファイルを追加
git add .

# タイトル（日付 + 日本語）と、短い説明を付けてコミット
git commit -m "26/11/07 購入日の表示を統一" -m "- 全画面で YYYY年MM月DD日 にそろえた"
```

#### ④ push する（GitHubに送る）
```bash
git push origin fujita
```

#### ⑤ プルリクエスト（PR）を作成してマージする
1. GitHubのリポジトリを開き、**Compare & pull request**（または **Pull requests** → **New pull request**）を押します。
2. **base** を `main`、**compare** を自分のブランチにします。
3. タイトル（日付 + 日本語）と、本文（変更内容を日本語で簡素に）を書いて、**Create pull request** を押します。
4. 内容を確認して、**Merge pull request** でマージします。
