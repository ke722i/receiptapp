# カテゴリ表（Excel）を更新する方法

商品やカテゴリを増やしたいときの手順です。

## 全体の流れ

| 手順 | やること | だれが |
|---|---|---|
| ① | Excel（`tools/categoryTable.xlsx`）を編集して、同じ場所に上書き保存する | あなた |
| ② | Claude に「カテゴリ表を更新して」と言う | あなた |
| ③ | カテゴリ表を作り直して、変更点を報告する | Claude |
| ④ | `npm run deploy-functions` を実行する | あなた |
| ⑤ | コミット → PR → マージ | あなた |

## ① Excel を編集する

- 場所: `tools/categoryTable.xlsx`
- 大分類ごとにシートがあります。並びは **中分類 → 小分類 → 商品名** です。
- 行を足すときは、隣の行と同じ形（番号・列の位置）で書きます。
- **「その他」は入れません**（アプリが自動で付けます）。
- 編集する前に、**最新のファイルか**確認してください。Claude や提案の反映で、更新されていることがあります。

## ② Claude に頼む

「**カテゴリ表を更新して**」と言うだけです。Claude が、次を行います。
- カテゴリのデータを作り直す
- 漢字の読み仮名が足りなければ、足す（ホームの検索で、ひらがなで探すため）
- 増えた・減った項目を報告する
- アプリが動くか（build）確認する

## ④ デプロイする

```
npm run deploy-functions
```
- 実行するまで、AI の解析は、古いカテゴリ表のままです。
- 実行には、Supabase へのログインが必要です。

## ⑤ 公開する

コミット → GitHub で PR を作る → `main` にマージ（アプリの画面に反映されます）。

## 注意

- 古い Excel を上書きすると、前の更新が消えます。
- 商品名を変えると、すでに登録したレシートのカテゴリとは、名前が合わなくなることがあります。

# 店名（チェーン）を追加する方法

レシートの店名を、「チェーン名 支店名」の形にそろえるための辞書に、新しいチェーンを足します。

1. Claude に「**店名を追加して**」と言う
2. 追加したい店名と、レシートに印字される書き方（カタカナ・英字など）を伝える
3. Claude が追加して、結果を報告する
4. コミット → PR → マージ

**ポイント**
- 「玉出」のような地名や短い言葉は、支店名と間違えるので、キーワードにしません。
- 別のお店として分けたいものは、別の項目にします（例: ローソンストア100）。

## 分類の間違いの記録から、辞書を作る（同じ印字名を、次から正しく分類する）

| 手順 | すること |
|---|---|
| 1 | `tools/wrongCategory.xlsx` に、間違いを書き足す（印字名、カテゴリの上の行 = 間違い、下の行 = 正しい分類。わからなければ「？」） |
| 2 | `python tools/build_print_dictionary.py --check` で、入る数と、入らなかった記録を見る |
| 3 | `python tools/build_print_dictionary.py` で、辞書を作る |
| 4 | `npm run deploy-functions` で、レシートの解析に反映する |
| 5 | コミット → PR → マージ |

**ポイント**
- 正しい分類の名前は、今のカテゴリ表にある名前（商品名・小分類・中分類）で書きます。表に無い名前（例: ケーキ）は、入りません。アプリの提案で、表に足したあとに、作り直すと入ります。
- 印字名が、ぴったり同じときだけ使います（全角半角・空白・大文字小文字の違いは、同じとみなします）。
- 同じ印字名で、正しい分類が食い違う記録は、入りません（どちらが正しいか、決められないため）。
