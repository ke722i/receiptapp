# はじめに（このマニュアルの使い方）

このファイル（マニュアル.xlsx）に、**あなたがやる作業**の手順を、まとめています。タブごとに、1 つの作業です。
Claude が読む決まりや仕様は、別のファイルにあります（あなたは、読まなくてよいです）。

## タブの一覧

| タブ | 入っているもの | こんなとき |
|---|---|---|
| はじめに | 今見ているタブ。ファイルの場所と、困ったときの見先 | 何がどこにあるか、わからなくなったとき |
| コマンド早見表 | 自分で実行するコマンドと、Claude への指示の言い方 | 何を打てばいいか、わからなくなったとき |
| 公開の流れ | コミット → PR → マージ → デプロイ | 変更を、公開サイトに出すとき |
| 管理者 | 管理者の画面の使い方（提案の承認・分類の修正・お知らせ・アカウント） | 管理者の画面で、作業するとき |
| 提案の承認 | カテゴリの提案の承認と、表への反映 | 提案が届いたとき |
| レシート取り込み | Gemini のチャットで入力したレシートを、DB に入れる方法 | レシートの JSON を取り込むとき |
| カテゴリ表・辞書 | カテゴリ表の更新、店名の追加、印字名の辞書、店舗名の表記ゆれ | 分類を直したいとき |
| アイコン | 商品アイコンの追加 | アイコンを足したいとき |
| DBを調べる | DB を、読み取り専用で調べる準備 | DB の件数などを調べたいとき |

## ファイルの場所

| 場所 | 入っているもの | だれが使う |
|---|---|---|
| マニュアル.xlsx | このファイル（あなた用の手順） | あなた |
| CLAUDE.md、docs/claude/ | Claude が読む決まりと仕様 | Claude（あなたは、読まなくてよい） |
| docs/manual/ | このマニュアルの元の文章（直すときは、Claude に頼む） | Claude |
| PROGRESS.md | 作業の記録（「引継ぎして」で更新） | Claude・あなた |
| TEST_ITEMS.md、TEST_ITEMS.xlsx | テスト項目書 | テストする人 |
| tools/categoryTable.xlsx | カテゴリ表（あなたが直す） | あなた |
| tools/wrongCategory.xlsx | 分類の間違いの記録（あなたが書き足す。Git に入らない） | あなた |
| tools/dictionary_candidates.xlsx | 辞書に入れる候補（あなたが確認する。Git に入らない） | あなた |
| tools/receipt_json/ | Gemini の JSON を置く場所 | あなた |
| tools/ | コマンド・ツール | Claude・あなた |
| supabase/migrations/ | DB を変える SQL（実行は、Supabase の SQL Editor で、あなたが行う） | あなた |
| misc/ | 使い終わったファイル・古い作業ファイル（Git に入らない。なくなっても困らない） | あなた |
| .env、.db-readonly.url、.import-uid | 秘密・設定（Git に入らない。Claude は開かない） | あなた |

## 困ったときは

| やりたいこと | 見るタブ |
|---|---|
| 変更を公開したい | 公開の流れ |
| 「コミットして」など、Claude への言い方を知りたい | コマンド早見表 |
| レシートを Gemini で入力して、DB に入れたい | レシート取り込み |
| 商品の分類の間違いを、次から直したい | カテゴリ表・辞書（または、管理者 →「分類の修正」） |
| 店舗名が、別々に分かれている | カテゴリ表・辞書（「店舗名の表記ゆれ」） |
| カテゴリの提案が届いた | 提案の承認 |
| 0 件のカテゴリや、未選択の件数を調べたい | DBを調べる |
| お知らせを出したい | 管理者 |

## マニュアルを作り直す

文章を直したあと、次を実行すると、このファイルが、最新になります（Excel は、閉じておく）。

```
npm run manual
```
