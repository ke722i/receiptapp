# 提案の承認のしかた（管理者向け）

ユーザーが「カテゴリを提案」したときに、承認か見送りを決めて、カテゴリ表に足すまでの手順です。

## 全体の流れ

| 手順 | やること | どこで |
|---|---|---|
| ① | 提案を見て、承認か見送りを決める | アプリの管理者画面 |
| ② | 承認した提案を CSV で保存する | アプリの管理者画面 |
| ③ | CSV を `tools/proposals/` に入れて、Claude に「承認したものを追加して」と言う | パソコン |
| ④ | Claude が、カテゴリ表に足して、作り直す | （Claude の作業） |
| ⑤ | `npm run deploy-functions` を実行し、PR をマージする | パソコン・GitHub |

**覚えておくこと**
- ①で承認すると、提案した人にすぐ通知が届きます。
- ただし、全員の画面と AI に出るのは、⑤が終わってからです。

## ① 承認か見送りを決める

1. 設定 → **管理者メニュー** → 「カテゴリの提案の承認」を開く
2. 「承認待ち」の提案が、カードで出る（同じ提案は、人数でまとまる）
3. メモ欄に理由を書く（空でもよい）
4. 「**承認**」か「**見送り**」を押す

- メモは、提案した人の通知に出ます。
- 承認でメモが空なら、「次の更新で追加します」と自動で入ります。
- 間違えたら、「承認」「見送り」のタブで「承認待ちに戻す」を押します。

**決めるときの目安**
- 今のカテゴリ表に、同じ・似たものがないか
- 大分類・中分類・小分類の場所が合っているか
- 名前として自然か
- 何人が提案したか、商品の例

## ② CSV で保存する

1. 管理者画面の「**承認**」タブを開く
2. 「承認した提案を CSV で保存」を押す
3. ダウンロードされたファイルを、`tools/proposals/` フォルダに入れる

## ③ Claude に頼む

- 新しい**中分類**・**小分類**を承認したときは、入れる商品名が必要です。
  - CSV を開いて、`products` の列に商品名を「、」区切りで書く
  - または、Claude に「商品名の案を作って」と頼む
- 商品名の提案だけ承認したときは、そのままで大丈夫です。
- Claude に、**「承認したものを追加して」**と伝えます。

## ⑤ 公開する

1. `npm run deploy-functions` を実行する（AI の解析に反映）
2. コミット → PR を作る → `main` にマージする（アプリの画面に反映）

## 注意

- Claude が Excel（`tools/categoryTable.xlsx`）に足したあとは、**そのファイルを使って**ください。古いコピーで上書きすると、足した分が消えます。
- すでに「その他」で登録したレシートは、自動では移りません。移したいときは、Claude に頼んでください。

## 最初の 1 回だけの準備

1. Supabase の SQL Editor で、`supabase/migrations/20261116000000_admin_proposals.sql` を実行する
2. 管理者にするアカウントの UID を調べる（Supabase の Authentication → Users）
3. 次の SQL を実行する
   ```sql
   insert into public.app_admins (user_id) values ('ここにUID') on conflict do nothing;
   ```
4. そのアカウントでログインして、設定画面に「管理者メニュー」が出るか確認する

**管理者を外すとき**
```sql
delete from public.app_admins where user_id = 'ここにUID';
```
