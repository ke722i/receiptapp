# 商品アイコンを追加する方法

商品詳細の画像の枠と、ホームの「お気に入り」に出る、商品のアイコンの追加手順です。

## 全体の流れ

| 手順 | やること | だれが |
|---|---|---|
| ① | アイコンの Excel に、ファイル名と商品名を書く | あなた |
| ② | SVG の画像を、フォルダに入れる | あなた |
| ③ | Claude に「アイコン」と言う | あなた |
| ④ | 対応表を作って、足りないものを報告する | Claude |
| ⑤ | コミット → PR → マージ | あなた |

## ① Excel を書く

- 場所: `tools/categoryIcon.xlsx`
- 書き方:

| 列 | 内容 | 例 |
|---|---|---|
| B 列 | アイコンのファイル名（`.svg` は付けない） | `アイス` |
| G 列 | そのアイコンを使う商品名（「、」で区切る） | `アイスクリーム類、シャーベットの素` |

- **商品名の文字の色**で、大分類を区別します（Excel の 1 行目にも書いてあります）。

| 色 | 大分類 |
|---|---|
| 緑 | 常温 |
| 青 | 冷蔵 |
| オレンジ | 冷凍 |
| 赤 | 日用品 |

- **アイコンを用意していない商品**（新しく増えた商品・アプリ内の提案で追加された商品）は、**同じ小分類 → 同じ中分類で、いちばん多く使われているアイコン**が、自動で使われます（例: 玄米茶 → お茶のペットボトル）。Excel に書かなくても、画像が出ます。
- 同じ名前の商品が、常温にも冷凍にもあるときは、色を付けて区別します。
- **同じ大分類の中で、同じ名前の商品が、別の中分類にもあり、アイコンを変えたい**ときは、Claude に伝えてください（例: 魚の「ぶり」は、切り身・丸魚が「さかなたち」、刺身・寿司ネタが「すし」）。`tools/categoryIconOverrides.json` に書いて、反映します。Excel には、両方のアイコンの行に、その商品名を書いておきます。
- **色を付けない名前は、その名前がある大分類すべてに、同じアイコンが付きます**（絵が同じでよいときは、色なしで 1 回書けば足ります）。
- 商品名は、カテゴリ表と**同じ書き方**にします（全角・半角のかっこや、漢字の違いに注意）。

## ② SVG を入れる

- 場所: `src/assets/categoryIcons/`
- ファイル名は、Excel の B 列と**完全に同じ**にします（例: `アイス.svg`）。
- 大きいファイル（目安: 1 つ 10KB 超）は、アプリが重くなります。

## ③ Claude に頼む

「**アイコン**」と言うだけです。Claude が、次を行います。
- 対応表を作る
- 次の問題を報告する
  - 表に無い商品名（表記のゆれ）
  - 色と大分類が合わないもの
  - SVG が無いアイコン
- SVG が大きいときは、まとめて軽くする（元のファイルは `tools/svg_original/` に残ります）

**注意**
- Excel に無い SVG や、SVG の無いアイコンは、そのまま無視されます。
- 軽くした SVG は、絵が崩れていないか、**あなたの目で確認**してください。

## ⑤ 公開する

コミット → GitHub で PR を作る → `main` にマージ。公開サイトに、アイコンが出ます。
