# 管理者の画面の使い方

管理者のアカウントでログインすると、**管理者ホーム**が最初に開きます。
一般のユーザーには、管理者の画面は出ません。

## 管理者ホームでできること

| 機能 | できること |
|---|---|
| 利用状況 | 登録ユーザー数、レシート数、今日の解析の回数などを見る |
| 提案の承認 | カテゴリの提案を、承認・見送りにする（→ `proposal-approval.md`） |
| お知らせの配信 | 全員のホームに、お知らせを出す |
| アカウントの管理 | テスト用・管理者の権限を付ける、ユーザー別の解析の回数を見る |

- 「**一般の画面を見る**」で、一般のユーザーと同じホームに行けます（展示や動作の確認に）。
- 一般のホームから戻るときは、ハンバーガーメニュー → 「**管理者ホーム**」。
- 管理者のアカウントには、黄色い「**管理者**」の印が出ます。

## 利用状況

| 数字 | 意味 |
|---|---|
| 登録ユーザー | アカウントの数（下に、直近 7 日の増え方） |
| レシート | 登録されたレシートの数（下に、直近 7 日の増え方） |
| 商品（明細） | レシートの商品の行の数 |
| 今日の解析 | 今日、AI で解析した回数（全員の合計） |
| 価格の共有オン | 価格データの共有をオンにしている人の数 |
| 提案 | 承認待ちの数（下に、承認・見送りの数） |

- 「↻ 更新」で、最新の数字にします。

## お知らせの配信

1. 管理者ホーム → 「**お知らせの配信**」
2. タイトル（60 文字まで）と本文（任意、500 文字まで）を書く
3. 「**配信する**」を押す

- 全員のホームの、いちばん上に出ます（新しい順に 5 件まで）。
- ユーザーは「✕」で閉じられます。**内容を直すと、もう一度出ます**。
- 「すぐに公開する」のチェックを外すと、**下書き**で保存できます。
- 一覧から「直す」「公開を終える／公開する」「消す」ができます。

## アカウントの管理

1. 管理者ホーム → 「**アカウントの管理**」
2. ログイン ID で探す、並び順を変える（登録が新しい順、解析が多い順）

**1 人ずつ見られること**
- 登録日、最後のログイン、レシートの数、価格の共有のオン・オフ
- **解析の回数**: 今日（30 回が上限。上限に達すると赤）、直近 7 日、合計

**変えられること**

| チェック | 意味 |
|---|---|
| テスト用 | 価格の共有の上限（1 人につき直近 3 件）をかけない。押すとすぐ変わる |
| 管理者 | 管理者の画面を使えるようにする。確認のあとで変わる |

- **自分自身の管理者は外せません**（管理者が 0 人にならないように）。外すときは、別の管理者が行います。

## 最初の 1 回だけの準備

1. Supabase の SQL Editor で、次の 2 つを、この順に実行する
   - `supabase/migrations/20261116000000_admin_proposals.sql`
   - `supabase/migrations/20261116100000_admin_tools.sql`
2. 最初の管理者を、SQL で登録する（2 人目からは、アカウントの管理の画面で付けられます）
   ```sql
   insert into public.app_admins (user_id) values ('ここにUID') on conflict do nothing;
   ```
   - UID は、Supabase の Authentication → Users で確認

## 知っておくこと

- 管理者にも、他のユーザーのレシートの中身（店・商品・値段）は見えません。見えるのは、数とログイン ID だけです。
- 権限は DB が確かめているので、一般のユーザーが管理者の機能を使うことはできません。
