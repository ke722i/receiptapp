# 商品のアイコン（tools/categoryIcon.xlsx）

## 元データのルール（Excel）
- B 列 = アイコンのファイル名（拡張子なし。`アイス` → `アイス.svg`）。G 列 = そのアイコンを使う商品名（「、」区切り）。「あ」「い」…の行は見出し。
- **商品名の文字の色 = 大分類**（1 行目に書いてある）: 常温＝緑、冷蔵＝青、冷凍＝オレンジ、日用品＝赤。1 つのセルの中で、商品名ごとに色が違ってよい（例: アイス = 「アイスクリーム類」オレンジ＋「シャーベットの素」緑）。
- 色を付けた名前は、その大分類だけに使う。**色なし（黒など）の名前は、その名前がある大分類すべてに、同じアイコンを使う**（常温と冷凍の両方にある「ビーフン」を 1 回、色なしで書けば、両方に付く）。大分類ごとに絵を変えたいものだけ、色を付けて書く（色を付けた大分類は、色なしの別のアイコンで上書きしない）。
- 商品は、名前＋大分類で決める（中分類・小分類は見ない）。1 つの商品に付けられるアイコンは 1 つだけ。

## 場所
- アイコンの SVG: `src/assets/categoryIcons/<ファイル名>.svg`（ユーザーが置く。無いものは、指示があれば作る）
- 対応表（生成物。直接編集しない）: `src/constants/categoryIconData.js` の `CATEGORY_ICON_MAP`（大分類 → 商品名 → ファイル名）

## 「アイコン」と指示されたときの手順
1. `python tools/parse_category_icons.py` を実行する（Excel を読み、対応表を作り、点検の結果を出す）。
2. 点検の結果を、ユーザーに短く報告する（アイコン数・対応した商品名・SVG が無いアイコン数）。次は、Excel を直してもらう（私は直さない）:
   - 表に無い商品名（Excel の表記が、カテゴリ表と違う）／色と大分類が合わない／アイコン名の重複／商品名が複数のアイコンにある
3. 画面への表示は作成済み（部品 `src/components/productIcon/productIcon.jsx`）: 商品詳細の右上の画像の枠、ホームの閲覧履歴のカード。SVG が無い・対応が無いときは、元の表示（「画像」／🛍️）のまま。出す場所を増やすときは、この部品を使う。SVG は、置いてビルドすれば自動で反映される。
4. `npm run build` が通ることを確認する。
- カテゴリ表（categoryTable.xlsx）を更新したあとは、手順 1 を実行し直す（商品名が変わると、対応が外れる）。
- 「その他」にはアイコンを付けない（表に無いため）。
